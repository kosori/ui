---
title: Button
description: A button triggers an action from a click, tap or keyboard input.
---

Button wraps the [Base UI Button](https://base-ui.com/react/components/button)
primitive, styles it with `cva` variants and marks it with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/button
```
