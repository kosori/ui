---
title: Field
description: A field groups a label, a control and a message.
---

Field composes [Label](/docs/kaze/label) and
[Separator](/docs/kaze/separator), and each part marks itself with `data-slot`.
The composition is shipped as two namespaced dependencies, so installing Field
installs the parts it needs.

## Installation

```bash
npx shadcn@latest add @kosori/field
```
