---
title: Button Group
description: A component for visually grouping a series of controls.
---

Button Group joins adjacent controls into one bordered row, removes the shared
edges, and separates them with `ButtonGroupSeparator` and `ButtonGroupText`. It
composes Base UI's `useRender` and `mergeProps` and marks itself with
`data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/button-group
```

<ComponentPreview name='button-group' />

## Usage

```tsx
import { Button } from '@/components/ui/button';
import { ButtonGroup } from '@/components/ui/button-group';

const ButtonGroupDemo = () => (
  <ButtonGroup>
    <Button variant='outline'>Previous</Button>
    <Button variant='outline'>Next</Button>
  </ButtonGroup>
);
```

## Variants

| Part | Prop | Values |
| --- | --- | --- |
| `ButtonGroup` | `orientation` | `horizontal`, `vertical` |
