---
title: Checkbox
description: A control allowing the user to toggle between checked and not checked.
---

Checkbox wraps Base UI's `Checkbox.Root` and ships a built-in indicator with
checkmark and indeterminate icons, marking itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/checkbox
```

## Example

<ComponentPreview name='checkbox' />

## Usage

```tsx
import { Checkbox } from '@/components/ui/checkbox';
import { Label } from '@/components/ui/label';

const CheckboxDemo = () => (
  <Label className='flex items-center gap-2'>
    <Checkbox defaultChecked />
    Enable notifications
  </Label>
);
```
