---
title: Collapsible
description: A collapsible panel controlled by a button trigger.
---

Collapsible wraps the
[Base UI Collapsible](https://base-ui.com/react/components/collapsible)
primitive, springs its panel height open and closed on the `smooth` preset, and
exposes `CollapsiblePanel` as `CollapsibleContent`. Once a panel settles open it
stops clipping, so nested content is not cut off. It is a client component: it
manages open state and marks each part with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/collapsible
```

## Usage

```tsx
import {
  Collapsible,
  CollapsiblePanel,
  CollapsibleTrigger,
} from '@/components/ui/collapsible';

const CollapsibleDemo = () => (
  <Collapsible>
    <CollapsibleTrigger>Show recovery keys</CollapsibleTrigger>
    <CollapsiblePanel>4829-1735-6621</CollapsiblePanel>
  </Collapsible>
);
```
