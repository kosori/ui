---
title: Collapsible
description: A collapsible panel controlled by a button trigger.
---

Collapsible wraps the
[Base UI Collapsible](https://base-ui.com/react/components/collapsible)
primitive, animates its panel height, and exposes `CollapsiblePanel` as
`CollapsibleContent`. It is a client component: it manages open state and marks
each part with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/collapsible
```
