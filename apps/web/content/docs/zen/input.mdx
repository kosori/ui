---
title: Input
description: A native input element.
---

Input wraps the [Base UI Input](https://base-ui.com/react/components/input)
primitive in a styled control, accepts `size`, `unstyled` and `nativeInput`, and
marks both parts with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/input
```

## Example

<ComponentPreview name='input' />

## Usage

```tsx
import { Input } from '@/components/ui/input';

const InputDemo = () => (
  <Input aria-label='Enter text' placeholder='Enter text' type='text' />
);
```
