---
title: Input OTP
description: A segmented input for one-time passwords and verification codes.
---

Input OTP wraps the [Base UI OTP
Field](https://base-ui.com/react/components/otp-field) primitive, renders
[Separator](/docs/zen/separator) between groups and marks each part with
`data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/input-otp
```

<ComponentPreview name='input-otp' />

## Usage

```tsx
import { OTPField, OTPFieldInput } from '@/components/ui/input-otp';

const InputOtpDemo = () => (
  <OTPField length={6}>
    <OTPFieldInput />
    <OTPFieldInput />
    <OTPFieldInput />
    <OTPFieldInput />
    <OTPFieldInput />
    <OTPFieldInput />
  </OTPField>
);
```
