---
title: Hover Card
description: A popup that appears when a link is hovered, showing a preview for sighted users.
---

Hover card wraps the [Base UI Preview Card](https://base-ui.com/react/components/preview-card)
primitive, positions its popup with Base UI's `Positioner` and marks each part
with `data-slot`. It exports `HoverCard` aliases over coss's `PreviewCard` names.

## Installation

```bash
npx shadcn@latest add @kosori/hover-card
```

<ComponentPreview name='hover-card' />

## Usage

```tsx
import { Button } from '@/components/ui/button';
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from '@/components/ui/hover-card';

const HoverCardDemo = () => (
  <HoverCard>
    <HoverCardTrigger render={<Button variant='ghost' />}>
      coss.com/ui
    </HoverCardTrigger>
    <HoverCardContent>
      Beautifully designed components you can copy and own.
    </HoverCardContent>
  </HoverCard>
);
```
