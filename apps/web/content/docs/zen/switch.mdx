---
title: Switch
description: A control that indicates whether a setting is on or off.
---

Switch wraps Base UI's `Switch.Root` with a built-in thumb whose size is
controlled by the `--thumb-size` CSS variable.

## Installation

```bash
npx shadcn@latest add @kosori/switch
```

## Example

<ComponentPreview name='switch' />

## Usage

```tsx
import { Switch } from '@/components/ui/switch';

const SwitchDemo = () => <Switch defaultChecked />;
```
