---
title: Radio Group
description: A set of checkable buttons where no more than one of the buttons can be checked at a time.
---

RadioGroup and Radio wrap Base UI's radio primitives with a flex column layout
and a built-in indicator; Radio also ships as `RadioGroupItem`.

## Installation

```bash
npx shadcn@latest add @kosori/radio-group
```

## Example

<ComponentPreview name='radio-group' />

## Usage

```tsx
import { Label } from '@/components/ui/label';
import { Radio, RadioGroup } from '@/components/ui/radio-group';

const RadioGroupDemo = () => (
  <RadioGroup defaultValue='email'>
    <Label className='flex items-center gap-2'>
      <Radio value='email' />
      Email
    </Label>
    <Label className='flex items-center gap-2'>
      <Radio value='sms' />
      SMS
    </Label>
  </RadioGroup>
);
```
