---
title: Tabs
description: A component for toggling between related panels on the same page.
---

Tabs wraps the [Base UI Tabs](https://base-ui.com/react/components/tabs)
primitive and shares the segmented-control item sizing that installs with it. It
supports the default and underline variants, horizontal and vertical
orientation, and exposes `TabsTab` as `TabsTrigger` and `TabsPanel` as
`TabsContent`.

## Installation

```bash
npx shadcn@latest add @kosori/tabs
```

## Usage

```tsx
import { Tabs, TabsList, TabsPanel, TabsTab } from '@/components/ui/tabs';

const TabsDemo = () => (
  <Tabs defaultValue='account'>
    <TabsList>
      <TabsTab value='account'>Account</TabsTab>
      <TabsTab value='password'>Password</TabsTab>
    </TabsList>
    <TabsPanel value='account'>Account settings</TabsPanel>
    <TabsPanel value='password'>Password settings</TabsPanel>
  </Tabs>
);
```
