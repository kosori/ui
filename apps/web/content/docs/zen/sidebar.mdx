---
title: Sidebar
description: A collapsible application sidebar for navigation.
---

Sidebar composes [Button](/docs/zen/button), [Input](/docs/zen/input),
[Scroll Area](/docs/zen/scroll-area), [Separator](/docs/zen/separator),
[Sheet](/docs/zen/sheet), [Skeleton](/docs/zen/skeleton) and
[Tooltip](/docs/zen/tooltip). It collapses to an icon rail on desktop and
becomes a Sheet below the `md` breakpoint. Every part carries a `data-slot` for
styling.

## Installation

```bash
npx shadcn@latest add @kosori/sidebar
```
