---
title: Motion
description: What animates in zen, which engine runs it, and how to tune it.
---

Motion is the time-based feedback a component gives in response to interaction
or a state change. `zen` runs it on two engines: the [`motion`
package](https://motion.dev) for anything that springs, travels or has to be
interrupted, and CSS for everything that only changes colour, shadow or
position.

## What animates

| Surface | Engine | Preset |
| --- | --- | --- |
| Button and Toggle press | Motion | `snappy` |
| Switch thumb, Checkbox, Slider | Motion | `snappy`, `responsive` |
| Accordion and Collapsible height | Motion | `smooth` |
| Dialog, Sheet, Alert Dialog | Motion | `smooth` |
| Popover, menus, Command, Select, Combobox, Autocomplete | Motion | `snappy` |
| Tooltip and Preview Card | Motion | `snappy` |
| Tabs and segmented highlights | Motion | `morph` |
| Toast and Drawer | CSS | — |
| Sidebar collapse | CSS | — |
| Progress and Meter | CSS | — |
| Colour, shadow, border, hover, focus | CSS | — |

Toast and Drawer stay on CSS on purpose. Both run on Base UI's per-frame swipe
and stack variables — `--toast-index`, `--drawer-swipe-progress`,
`--drawer-swipe-strength` — and moving them to Motion would mean reimplementing
that math in JavaScript. Sidebar animates `width` and `margin`, where a spring
would distort the content inside it. Progress and Meter change on every value
update, and an animation repeated that often stops reading as feedback.

## Presets

Springs ship in `lib/motion.ts`. Every install of a component that needs Motion
writes that file, and it is yours to edit.

| Preset | Values | Used for |
| --- | --- | --- |
| `snappy` | `visualDuration: 0.26`, `bounce: 0` | Presses, toggles, thumbs, small indicators |
| `smooth` | `visualDuration: 0.4`, `bounce: 0` | Panels, height changes, dialogs, sheets |
| `morph` | `visualDuration: 0.42`, `bounce: 0` | Shared highlights and widths that follow content |
| `responsive` | `stiffness: 520`, `damping: 44` | Direct manipulation that tracks the pointer |
| `gentle` | `stiffness: 340`, `damping: 34` | Larger layout changes |

Press feedback animates `scale`: `motionTokens.pressScale` defaults to `0.97`
and lives beside the presets.

```tsx
import { motion } from 'motion/react';
import { useMotionTransition } from '@/lib/motion';

export function Thumb({ on }: { on: boolean }) {
  const transition = useMotionTransition('snappy');

  return <motion.span animate={{ x: on ? 20 : 0 }} transition={transition} />;
}
```

## Easing and duration

CSS transitions use the Style's Tokens, so a Theme change moves them with
everything else.

| Token | Value | Used for |
| --- | --- | --- |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | Default for UI transitions |
| `--ease-enter` | `cubic-bezier(0.2, 0, 0, 1)` | Elements arriving on screen |
| `--ease-spring` | `cubic-bezier(0.32, 0.72, 0, 1)` | A gentle settle, paired with `--duration-drawer` |
| `--duration-fast` | `160ms` | Hover, colour and small state changes |
| `--duration-standard` | `240ms` | Panels, menus and the Sidebar collapse |
| `--duration-considered` | `480ms` | Toast stacking and other deliberate reveals |
| `--duration-drawer` | `450ms` | The Drawer's swipe settle, off the shared scale |

A timing value belongs to one engine. Springs are never mirrored as CSS
variables, and easing is never duplicated in `lib/motion.ts`.

## Reduced motion

Every component reads the preference itself through `useMotionTransition()`,
which wraps `useReducedMotion()` and collapses its preset to an instant change.
There is no provider to mount and no change to your layout — installing a
component is the whole setup.

Under reduced motion the end state, focus and feedback are kept and travel is
removed:

- Presses and toggles jump to their end state; colour feedback still runs.
- Expandables snap open and closed.
- Dialogs, sheets and popups fade on opacity alone, with no scale and no travel.

## Editing

`lib/motion.ts` and the Tokens are copied source, like every kosori component.
Tune a preset once and every component that references it follows. Nothing in
the library reads your animation configuration from anywhere else.
