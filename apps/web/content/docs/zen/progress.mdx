---
title: Progress
description: Displays the status of a task that takes a long time.
---

Progress wraps the [Base UI
Progress](https://base-ui.com/react/components/progress) primitive and composes
its label, track, indicator and value parts. Root renders a default track and
indicator when it has no children, and each part marks itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/progress
```

<ComponentPreview name='progress' />

## Usage

```tsx
import { Progress } from '@/components/ui/progress';

const ProgressDemo = () => <Progress value={60} />;
```
