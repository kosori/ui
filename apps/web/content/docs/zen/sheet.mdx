---
title: Sheet
description: A flyout that opens from the side of the screen, based on the dialog component.
---

Sheet wraps the [Base UI Dialog](https://base-ui.com/react/components/dialog)
primitive, composes [Button](/docs/zen/button) and its scrollable panel through
Base UI's `render` prop, and marks each part with `data-slot`. It is a client
component: it opens from any edge, uses a portal, manages focus, and animates
with `tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/sheet
```

## Usage

```tsx
import { Button } from '@/components/ui/button';
import {
  Sheet,
  SheetClose,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetPopup,
  SheetTitle,
  SheetTrigger,
} from '@/components/ui/sheet';

const SheetDemo = () => (
  <Sheet>
    <SheetTrigger render={<Button variant='outline' />}>
      Open sheet
    </SheetTrigger>
    <SheetPopup>
      <SheetHeader>
        <SheetTitle>Edit profile</SheetTitle>
        <SheetDescription>Make changes to your profile.</SheetDescription>
      </SheetHeader>
      <SheetFooter>
        <SheetClose render={<Button variant='outline' />}>Cancel</SheetClose>
        <Button>Save changes</Button>
      </SheetFooter>
    </SheetPopup>
  </Sheet>
);
```
