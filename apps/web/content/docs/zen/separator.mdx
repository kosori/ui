---
title: Separator
description: A separator element accessible to screen readers.
---

Separator wraps the [Base UI
Separator](https://base-ui.com/react/components/separator) primitive, defaults
to horizontal and marks itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/separator
```

## Example

<ComponentPreview name='separator' />

## Usage

```tsx
import { Separator } from '@/components/ui/separator';

const SeparatorDemo = () => (
  <div className='flex flex-col gap-4'>
    <p>Above</p>
    <Separator />
    <p>Below</p>
  </div>
);
```
