---
title: Dialog
description: A dialog overlays the page with content that needs a response.
---

Dialog wraps the [Base UI Dialog](https://base-ui.com/react/components/dialog)
primitive, composes [Button](/docs/zen/button) through Base UI's `render` prop,
and marks each part with `data-slot`. It is a client component: it uses a
portal, manages focus, and animates with `tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/dialog
```
