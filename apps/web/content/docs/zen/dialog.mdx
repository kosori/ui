---
title: Dialog
description: A popup that opens on top of the entire page.
---

Dialog wraps the [Base UI Dialog](https://base-ui.com/react/components/dialog)
primitive, composes [Button](/docs/zen/button) and its scrollable panel through
Base UI's `render` prop, and marks each part with `data-slot`. It is a client
component: it uses a portal, manages focus, and animates with
`tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/dialog
```

## Usage

```tsx
import { Button } from '@/components/ui/button';
import {
  Dialog,
  DialogClose,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogPopup,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';

const DialogDemo = () => (
  <Dialog>
    <DialogTrigger render={<Button variant='outline' />}>
      Open dialog
    </DialogTrigger>
    <DialogPopup>
      <DialogHeader>
        <DialogTitle>Manage team member</DialogTitle>
        <DialogDescription>View and manage a team member.</DialogDescription>
      </DialogHeader>
      <DialogFooter>
        <DialogClose render={<Button variant='outline' />}>Cancel</DialogClose>
        <Button>Save changes</Button>
      </DialogFooter>
    </DialogPopup>
  </Dialog>
);
```
