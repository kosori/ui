---
title: Tooltip
description: A popup that appears when an element is hovered or focused, showing a hint for sighted users.
---

Tooltip wraps the [Base UI Tooltip](https://base-ui.com/react/components/tooltip)
primitive, positions its popup with Base UI's `Positioner` and marks each part
with `data-slot`. Grouped and detached triggers are available through
`TooltipProvider` and `TooltipCreateHandle`.

## Installation

```bash
npx shadcn@latest add @kosori/tooltip
```

## Usage

```tsx
import { Button } from '@/components/ui/button';
import {
  Tooltip,
  TooltipPopup,
  TooltipTrigger,
} from '@/components/ui/tooltip';

const TooltipDemo = () => (
  <Tooltip>
    <TooltipTrigger render={<Button variant='outline' />}>
      Hover me
    </TooltipTrigger>
    <TooltipPopup>Helpful hint</TooltipPopup>
  </Tooltip>
);
```
