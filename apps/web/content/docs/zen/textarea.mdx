---
title: Textarea
description: A native textarea element.
---

Textarea wraps a native `<textarea>` in Base UI's `Field.Control` so it composes
with Field, accepts `size` and `unstyled`, and marks both parts with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/textarea
```
