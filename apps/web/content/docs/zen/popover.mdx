---
title: Popover
description: An accessible popup anchored to a button.
---

Popover wraps the [Base UI Popover](https://base-ui.com/react/components/popover)
primitive, positions its popup with Base UI's `Positioner` and marks each part
with `data-slot`. Detached triggers are available through `PopoverCreateHandle`.

## Installation

```bash
npx shadcn@latest add @kosori/popover
```
