---
title: Select
description: A common form component for choosing a predefined value in a dropdown menu.
---

Select wraps the [Base UI
Select](https://base-ui.com/react/components/select) primitive, composes its
trigger, popup and items, and marks each part with `data-slot`. It is a client
component: it manages focus inside a portal and animates with
`tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/select
```

## Usage

```tsx
import {
  Select,
  SelectItem,
  SelectPopup,
  SelectTrigger,
  SelectValue,
} from '@/components/ui/select';

const frameworks = [
  { label: 'Next.js', value: 'next' },
  { label: 'Vite', value: 'vite' },
];

const SelectDemo = () => (
  <Select defaultValue='next' items={frameworks}>
    <SelectTrigger aria-label='Select framework'>
      <SelectValue />
    </SelectTrigger>
    <SelectPopup>
      {frameworks.map(({ label, value }) => (
        <SelectItem key={value} value={value}>
          {label}
        </SelectItem>
      ))}
    </SelectPopup>
  </Select>
);
```
