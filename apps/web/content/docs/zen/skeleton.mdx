---
title: Skeleton
description: A loading state skeleton for your components.
---

Skeleton renders a placeholder box with the `animate-skeleton` treatment and
marks itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/skeleton
```

## Example

<ComponentPreview name='skeleton' />

## Usage

```tsx
import { Skeleton } from '@/components/ui/skeleton';

const SkeletonDemo = () => <Skeleton className='h-4 w-48' />;
```
