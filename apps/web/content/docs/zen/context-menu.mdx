---
title: Context Menu
description: A menu that appears at the pointer on right click or long press.
---

Context menu wraps the [Base UI Context Menu](https://base-ui.com/react/components/context-menu)
primitive, positions its popup with Base UI's `Positioner` and marks each part
with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/context-menu
```

## Example

<ComponentPreview name='context-menu' />

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuItem,
  ContextMenuPopup,
  ContextMenuTrigger,
} from '@/components/ui/context-menu';

const ContextMenuDemo = () => (
  <ContextMenu>
    <ContextMenuTrigger className='flex h-32 w-full max-w-sm items-center justify-center rounded-lg border border-dashed'>
      Right click here
    </ContextMenuTrigger>
    <ContextMenuPopup>
      <ContextMenuItem>Edit</ContextMenuItem>
      <ContextMenuItem>Delete</ContextMenuItem>
    </ContextMenuPopup>
  </ContextMenu>
);
```
