---
title: Toggle
description: A two-state button that can be toggled on or off.
---

Toggle wraps the [Base UI
Toggle](https://base-ui.com/react/components/toggle) primitive with `cva`
variants for size and variant, and marks itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/toggle
```

## Example

<ComponentPreview name='toggle' />

## Usage

```tsx
import { Toggle } from '@/components/ui/toggle';

const ToggleDemo = () => <Toggle>Toggle</Toggle>;
```

## Variants

| Part | Prop | Values |
| --- | --- | --- |
| `Toggle` | `size` | `default`, `lg`, `sm` |
| `Toggle` | `variant` | `default`, `outline` |
