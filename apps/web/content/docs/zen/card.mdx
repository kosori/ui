---
title: Card
description: A content container for grouping related information.
---

Card composes Base UI's `useRender` and `mergeProps` into a header, panel,
footer and action layout, with `CardFrame` variants for framed groups. Every
part marks itself with `data-slot`, and `CardContent` is exported as an alias
of `CardPanel`.

## Installation

```bash
npx shadcn@latest add @kosori/card
```

## Usage

```tsx
import {
  Card,
  CardDescription,
  CardHeader,
  CardPanel,
  CardTitle,
} from '@/components/ui/card';

const CardDemo = () => (
  <Card className='w-full max-w-xs'>
    <CardHeader>
      <CardTitle>Create project</CardTitle>
      <CardDescription>Deploy your project in one click.</CardDescription>
    </CardHeader>
    <CardPanel>Card content</CardPanel>
  </Card>
);
```
