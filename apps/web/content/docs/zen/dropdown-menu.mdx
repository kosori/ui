---
title: Dropdown Menu
description: A list of actions in a dropdown, enhanced with keyboard navigation.
---

Dropdown menu wraps the [Base UI Menu](https://base-ui.com/react/components/menu)
primitive, composes [Button](/docs/zen/button) through Base UI's `render` prop
and marks each part with `data-slot`. It exports both coss's `Menu` names and
the `DropdownMenu` aliases.

## Installation

```bash
npx shadcn@latest add @kosori/dropdown-menu
```
