Each implemented component links to the page you install it from. Pending names
are shadcn/ui components that coss/ui has no equivalent for yet: they are listed
here so nothing is a dead end, and they have no page of their own. Compositions
are documented patterns that are not Registry items and never will be, so they
have a page but no installable name.
