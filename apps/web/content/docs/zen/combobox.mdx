---
title: Combobox
description: A searchable select for choosing one option or many.
---

Combobox composes Base UI's Combobox primitive with
[Input](/docs/zen/input) and [Scroll Area](/docs/zen/scroll-area), so filtering,
grouping and the popup share one model. Every part carries a `data-slot` for
styling.

## Installation

```bash
npx shadcn@latest add @kosori/combobox
```
