---
title: Combobox
description: A searchable select for choosing one option or many.
---

Combobox composes Base UI's Combobox primitive with
[Input](/docs/zen/input) and [Scroll Area](/docs/zen/scroll-area), so filtering,
grouping and the popup share one model. Every part carries a `data-slot` for
styling.

## Installation

```bash
npx shadcn@latest add @kosori/combobox
```

The Example below is a `registry:example` item, built and validated by the same

## Usage

```tsx
import {
  Combobox,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
  ComboboxPopup,
} from '@/components/ui/combobox';

const fruits = ['Apple', 'Banana', 'Orange'];

const ComboboxDemo = () => (
  <Combobox items={fruits}>
    <ComboboxInput placeholder='Search fruit' />
    <ComboboxPopup>
      <ComboboxEmpty>No fruit found.</ComboboxEmpty>
      <ComboboxList>
        {(fruit: string) => (
          <ComboboxItem value={fruit}>{fruit}</ComboboxItem>
        )}
      </ComboboxList>
    </ComboboxPopup>
  </Combobox>
);
```
