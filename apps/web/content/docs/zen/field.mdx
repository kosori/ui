---
title: Field
description: A component that provides labelling and validation for form controls.
---

Field wraps the [Base UI
Field](https://base-ui.com/react/components/field) primitive and ships the
Fieldset composition in the same item, so a form groups its labels, descriptions
and validation messages without a second install. Each part marks itself with
`data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/field
```

## Usage

```tsx
import {
  Field,
  FieldDescription,
  FieldLabel,
} from '@/components/ui/field';
import { Input } from '@/components/ui/input';

const FieldDemo = () => (
  <Field>
    <FieldLabel htmlFor='kosori-email'>Email</FieldLabel>
    <Input id='kosori-email' placeholder='you@example.com' type='email' />
    <FieldDescription>Shown on your public profile.</FieldDescription>
  </Field>
);
```
