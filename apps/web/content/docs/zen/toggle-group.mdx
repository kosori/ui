---
title: Toggle Group
description: Provides a shared state to a series of toggle buttons.
---

Toggle Group wraps the [Base UI Toggle
Group](https://base-ui.com/react/components/toggle-group) primitive, shares
`size` and `variant` with its Items through context, and marks itself with
`data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/toggle-group
```
