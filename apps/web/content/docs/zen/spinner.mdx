---
title: Spinner
description: An indicator that can be used to show a loading state.
---

Spinner wraps the Tabler `IconLoader2` icon, names it for assistive technology
with `role="status"` and spins it with `animate-spin`.

## Installation

```bash
npx shadcn@latest add @kosori/spinner
```

## Example

<ComponentPreview name='spinner' />

## Usage

```tsx
import { Spinner } from '@/components/ui/spinner';

const SpinnerDemo = () => <Spinner />;
```
