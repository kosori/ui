---
title: Drawer
description: A panel that slides in from the edge of the screen with swipe gestures, snap points, and nested drawer support.
---

Drawer wraps the
[Base UI Drawer](https://base-ui.com/react/components/drawer) primitive,
composes [Button](/docs/zen/button) and its scrollable panel through Base UI's
`render` prop, and marks each part with `data-slot`. It is a client component:
it supports swipe gestures, snap points and nested drawers, uses a portal,
manages focus, and animates with `tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/drawer
```
