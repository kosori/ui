---
title: Alert Dialog
description: A dialog that requires user response to proceed.
---

Alert Dialog wraps the
[Base UI Alert Dialog](https://base-ui.com/react/components/alert-dialog)
primitive, composes [Button](/docs/zen/button) through Base UI's `render` prop,
and marks each part with `data-slot`. It is a client component: it uses a
portal, manages focus, and animates with `tw-animate-css`.

## Installation

```bash
npx shadcn@latest add @kosori/alert-dialog
```
