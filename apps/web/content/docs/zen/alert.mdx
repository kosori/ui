---
title: Alert
description: A callout for displaying important information.
---

Alert is a `cva` variant map over a `div`, with `default`, `info`, `success`,
`warning` and `error` variants. Each state variant reads its colour from the
preset's semantic Tokens, and marks itself with `data-slot`.

## Installation

```bash
npx shadcn@latest add @kosori/alert
```

## Example

<ComponentPreview name='alert' />

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from '@/components/ui/alert';

const AlertDemo = () => (
  <Alert>
    <AlertTitle>Heads up!</AlertTitle>
    <AlertDescription>Your changes have been saved.</AlertDescription>
  </Alert>
);
```

## Variants

| Part | Prop | Values |
| --- | --- | --- |
| `Alert` | `variant` | `default`, `error`, `info`, `success`, `warning` |
