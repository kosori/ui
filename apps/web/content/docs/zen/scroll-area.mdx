---
title: Scroll Area
description: A native scroll container with custom scrollbars.
---

Scroll area wraps the [Base UI Scroll Area](https://base-ui.com/react/components/scroll-area)
primitive and ships vertical and horizontal scrollbars. Fade and gutter
behaviours are opt-in through `scrollFade` and `scrollbarGutter`.

## Installation

```bash
npx shadcn@latest add @kosori/scroll-area
```

<ComponentPreview name='scroll-area' />

## Usage

```tsx
import { ScrollArea } from '@/components/ui/scroll-area';

const ScrollAreaDemo = () => (
  <ScrollArea className='h-64 rounded-lg border'>
    <div className='p-4'>Scrollable content</div>
  </ScrollArea>
);
```
