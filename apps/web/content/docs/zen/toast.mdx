---
title: Toast
description: A temporary notification that appears on screen to inform users.
---

Toast wraps the [Base UI Toast](https://base-ui.com/react/components/toast)
primitive with a stacked viewport and an anchored variant. Mount
`ToastProvider` and `AnchoredToastProvider` once in your app, then call
`toastManager.add` or `anchoredToastManager.add`. `success`, `warning` and
`info` read their colour from the preset's semantic Tokens.

## Installation

```bash
npx shadcn@latest add @kosori/toast
```

## Usage

```tsx
'use client';

import { Button } from '@/components/ui/button';
import { ToastProvider, toastManager } from '@/components/ui/toast';

const Notify = () => (
  <Button
    onClick={() =>
      toastManager.add({ title: 'Saved', type: 'success' })
    }
    variant='outline'
  >
    Show toast
  </Button>
);

const ToastDemo = () => (
  <ToastProvider>
    <Notify />
  </ToastProvider>
);
```
