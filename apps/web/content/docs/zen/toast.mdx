title: Toast
description: A temporary notification that appears on screen to inform users.

Toast wraps the [Base UI Toast](https://base-ui.com/react/components/toast)
primitive with a stacked viewport and an anchored variant. Mount `Toaster` once
in your app, then call `toast.add` from anywhere. `ToastProvider`,
`toastManager`, `AnchoredToastProvider` and `anchoredToastManager` stay available
for the anchored surface. `success`, `warning` and `info` read their colour from
the preset's semantic Tokens.

kosori does not ship `sonner`: use `toastManager` from `@kosori/toast` instead.

## Installation

```bash
npx shadcn@latest add @kosori/toast
```

## Usage

Mount `Toaster` once, in your layout:

```tsx
import { Toaster } from '@/components/ui/toast';

const Layout = ({ children }: { children: React.ReactNode }) => (
  <Toaster>{children}</Toaster>
);
```

Then call `toast.add` from a client component:

```tsx
'use client';

import { Button } from '@/components/ui/button';
import { toast } from '@/components/ui/toast';

const Notify = () => (
  <Button
    onClick={() => toast.add({ title: 'Saved', type: 'success' })}
    variant='outline'
  >
    Show toast
  </Button>
);
```

Compose `Toast`, `ToastContent`, `ToastTitle`, `ToastDescription`,
`ToastAction` and `ToastClose` when a notification needs a custom layout.
